이 고민에는 이렇게 시작하세요

AI가 자연스럽게 설명해도 내용이 맞는다는 뜻은 아닙니다. 핵심 주장과 계산을 나누어 교재·원자료·직접 풀이로 확인하고, 확인하지 못한 내용은 과제의 근거로 쓰지 마세요.

먼저 살펴볼 세 가지

  • 답변의 어느 주장과 계산을 확인해야 하는지 표시합니다.
  • 제시한 출처가 실제로 존재하고 해당 내용을 담는지 봅니다.
  • 학생이 AI 없이 같은 이유를 설명할 수 있는지 확인합니다.

직접 해 보는 네 단계

  1. 질문 범위 좁히기

    정답 전체를 대신 만들게 하기보다 이해가 안 되는 개념이나 한 단계를 질문합니다. 학교의 AI 사용 기준과 서비스의 이용 조건을 먼저 확인하세요.

  2. 주장과 출처 나누기

    답변에서 사실·계산·추측을 구분합니다. 링크의 제목만 믿지 말고 원자료를 열어 내용과 날짜를 대조합니다.

  3. 직접 확인하기

    수학은 계산과 대입, 읽기는 원문 근거, 사실은 교재나 공식 자료로 확인합니다. AI에게 맞느냐고 다시 묻는 것만으로 검증을 끝내지 않습니다.

  4. 내 설명으로 다시 하기

    답변을 가리고 풀이하거나 요약합니다. 이해가 남지 않으면 필요한 한 부분을 교사에게 질문하고 제출물을 대신 작성하게 하지 않습니다.

연습 예시: AI가 2(x+3)=10에서 x=8이라고 답한 경우

처음 시도한 상황
그럴듯한 풀이 문장 때문에 정답으로 받아들였다고 가정합니다.
다시 확인할 내용
양변을 2로 나누면 x+3=5, 따라서 x=2입니다. 대입하면 2×(2+3)=10이고 x=8은 맞지 않습니다.
다른 조건에서 확인
새 식 3(y+2)=15를 직접 풀고 y=3을 대입해 설명합니다.

공부 방법을 익히기 위해 만든 연습 예시입니다. 실제 학생의 경험이나 성과를 나타내지 않습니다.
